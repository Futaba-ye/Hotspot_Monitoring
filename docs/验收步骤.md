# 网页版验收步骤

## 环境准备

按照根目录 [README](../README.md) 安装依赖并构建前端。复制 `.env.example` 为 `.env`，配置 `OPENROUTER_API_KEY`、`TWITTERAPI_IO_KEY` 及所需 SMTP 信息，重启后端。不要把密钥提交到仓库或发到聊天中。

## 功能验收

1. 打开 `http://127.0.0.1:8000`，确认首页正常显示；缩窄浏览器到约 390 像素，确认导航、卡片、表单和证据链接仍可使用。
2. 在“连接状态”确认 OpenRouter、X、邮件显示“已配置”，并在首次扫描后看到各来源最近的采集结果或明确错误。
3. 在“监控任务”创建“关键词提醒”和“领域发现”各一项，确认可以编辑、暂停、启用、手动扫描和删除。
4. 对关键词监控运行扫描，确认总览中每条线索有状态、中文摘要、判断理由和原始链接；单条未经核实的 X 内容不会生成提醒。
5. 对领域监控运行扫描，确认可按监控范围筛选，并切换“最新优先”和“热度优先”排序。
6. 使用实际出现且达到核实门槛的新事件，确认只产生一次网页提醒；配置 SMTP 后，收件地址收到邮件，重复扫描不会重复发送。
7. 暂时移除一个来源的配置或模拟来源故障，确认其他来源继续工作，错误在任务和连接状态中可见。
8. 执行 `python -m pytest -q` 与 `npm run build`，确认测试和构建通过。
